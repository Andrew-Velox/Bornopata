# Sample data

Tiny hand-written lists for CLI demos and tests. They are not a product dictionary and involve no third-party license.
They still follow the inherited pinyin format until the Bangla Core replaces it.

- `dict.tsv`: `word\tsyllables\tfrequency`
- `glossary-*.tsv`: `word\t[part of speech. ]gloss[\t[part of speech. ]gloss]`, one learning language per file
- `english.tsv`: word list for English-mode candidates, `word\tcode\tfrequency`
