- [Bornopata Settings](settings-program.md): the settings program in your app launcher.
- [The config file](config-file.md): every option, with its default.
- [Themes and the window](themes.md): the five themes, light and dark, vertical and horizontal, and which window is used where.
- [The dictionary](dictionary.md): the word list behind the candidates.

Everything the program changes is stored in `~/.config/bornopata/config.toml`, which you can also edit by hand.
