# Sakura theme art

- `images/*.svg` (bow, crown, sparkle, blossom, petal): drawn for Bornopata, GPL-3.0-or-later with the theme.
- `images/character.png`: the mascot, a pink chibi girl with a green leaf hairpin peeking over the top edge. Supplied by the project owner on 2026-10-21, generated with ChatGPT from an original prompt (no existing character named, pink twin tails, bows and a leaf hairpin that echoes the logo). It was trimmed to its transparent bounds and scaled to 312 by 205 pixels, which is 104 by 68 points at the theme's `scale` of 3. Check the generator's terms before making the repository public.
