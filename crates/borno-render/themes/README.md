# Theme art and its licenses

Each theme folder has a `theme.json`, SVG decoration and, for four of the themes, character pictures. The `README.md` in the folder says which is which and where the pictures come from.

- **`theme.json` and the SVG files** are GPL-3.0-or-later, like the rest of Bornopata.
- **The character pictures** (`character.png` and `character-lying.png` in `sakura`, `shapla`, `borsha` and `jonaki`) are original characters made by the project owner, Andrew-Velox, and the owner keeps the rights to them. They are **not** licensed under the GPL. A theme that has them says `GPL-3.0-or-later AND LicenseRef-Character` in `meta.license`; `LicenseRef-Character` means this part.

This follows the rule Qingjian, where the code comes from, uses for the character pictures of its themes.

## What you may do with the character pictures

- Copy and share them **unchanged together with Bornopata**: in a package, an installer, a mirror or a fork that keeps the themes.
- Show them to describe Bornopata, for example in a review or a screenshot.

For anything else, such as using them in another project or product, changing them or using the characters as a brand, ask the owner first. A fork that does not want them can delete the four `character*.png` files and the `fill` entries in `theme.json` that point to them; the themes still work with the decoration alone.

The characters are not taken from any existing work, and none of them is a real person.
